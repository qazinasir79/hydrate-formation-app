Method (paper’s formulation, implemented as published)

fwH(T,P) = fwβ(T,P) · exp( Σm νm ln(1 − Σj θmj) ),   θmj = Cmj fj / (1 + Σj Cmj fj)
Cmj(T) = (4π/kT) ∫₀Rm−2a exp(−w(r)/kT) r² dr   (McKoy–Sinanoğlu cell potential, Kihara core a)
w(r) = 2zε [ (σ¹²/R¹¹r)(δ¹⁰ + (a/R)δ¹¹) − (σ⁶/R⁵r)(δ⁴ + (a/R)δ⁵) ],  δN = (1/N)[(1−r/R−a/R)−N − (1+r/R−a/R)−N]
fwβ = exp(A − B/T) · exp( Vβ(T,P)(P − fβ)/RT )
Vβ(sI) = (11.835 + 2.217·10⁻⁵T + 2.242·10⁻⁶T²)³·10⁻³⁰NA/46 + 1.5265·10⁻⁹(P−0.1) − 2.8106·10⁻¹²(P−0.1)²
Vβ(sII) = (17.13 + 2.249·10⁻⁴T + 2.013·10⁻⁶T² + 1.009·10⁻⁹T³)³·10⁻³⁰NA/136 − 8.006·10⁻⁹P + 5.448·10⁻¹²P²  (P in MPa)
PRSV2: κ = κ₀ + [κ₁ + κ₂(κ₃−Tr)(1−√Tr)](1+√Tr)(0.7−Tr),  κ₀ = 0.378893 + 1.4897153ω − 0.17131848ω² + 0.0196554ω³
van Laar mixing: aij = √(aiaj)(1 − kijkji/(xikij + xjkji))),  kij(T) = pijT + qij; gas–gas kij = 0 (paper)
Equilibrium: fwH = fwL (H–LW–V / H–LW–LC) or fwH = fwI (H–I–V, T < 273.15 K, via exact ice bridge). Structure with the lower P wins.
Fluid fugacities from PRSV2 with the paper’s temperature-dependent water–gas kij; two-phase TP flash by successive substitution + Rachford–Rice (zero-feed components kept exactly zero). H–I–V branch: fice = psat,ice·exp(Vice(P−psat,ice)/RT), psat,ice = exp(28.89 − 6134.9/T) Pa, Vice = 19.65 cm³/mol.

Calibration procedure

The paper’s printed Kihara parameters (Table 2) are internally inconsistent with its own results (below), so the model was calibrated in this work against ≈70 reference equilibrium points (Sloan & Koh compilation; Zenodo CO₂ low-temperature data) plus the paper’s Tables 6–8 occupancies and the Fig. 5 transition state. Objective (stage 1): fugacity residuals ln(fwH/fwL) at each anchor (paper Eq. 27), scaled by the local sensitivity |∂r/∂lnP| so that saturated-cage (flat) regions carry their true pressure error; per-anchor structure hinges enforce the correct sI/sII selection; a weak regularization tethers Langmuir constants to Pollard–Petersen-type correlations. Stage 2 then freezes this Kihara/fβ set and regresses the aqueous-phase k(g,w) correction (dK₀, dK₁ — Parameters tab) against root-space residuals ln(Peqmodel/Peqexp), computed by bracketing the true equilibrium root at each anchor (never by evaluating the residual at Pexp, which admits spurious roots), plus the experimental solubility anchors. The final fit reproduces:

  • all pure-gas structures: CH₄/C₂H₆/CO₂ sI (incl. ice branch), C₃H₈ sII, N₂ sII;
  • occupancies within 1.3% of paper Tables 6–8;
  • Fig. 5 sI→sII onset at y(C₃H₈) ≈ 3·10⁻⁴ (paper 5·10⁻⁴) at 4.0 MPa, 277.6 K;
  • natural gas sII curve (Fig. 7) with the right trend and magnitude;
  • H–LW–V pressures of CH₄, C₂H₆, CO₂, C₃H₈ typically within 0.2–12%.
  • gas solubilities in water within ±20% for C₂H₆, C₃H₈, N₂, CO₂ and ×2–3 for CH₄ (paper Fig. 1 anchors).

Paper inconsistencies found (why deviations exist)

  1. Table 2 Kihara parameters are unusable as printed. In a standard McKoy–Sinanoğlu implementation with Eqs. (16)–(17), they yield θS(CH₄, 273.2 K) ≈ 0.01 vs Table 6’s 0.935, Peq(CH₄) errors ≈ ×100, and vanishing Langmuir constants for C₃H₈/CO₂ (σ larger than the cage free radius). They cannot be the values the authors’ code used.
  2. Table 6 occupancies contradict the printed Martín–Peters fβ. θ = (0.969, 0.935) at 273.2 K with fβ,sI(273.15) = exp(28.4−5800/T) = 1295 Pa gives fwH = 748 Pa vs fwL ≈ 600 Pa — 25% off equilibrium. fβ,sI(273.15) ≈ 1050–1100 Pa (this work’s fitted value) reconciles Tables 6–8 with the equilibrium data.
  3. Table 7’s caption repeats Table 6’s text (both are CH₄; the 276.7 K data are indeed CH₄).
  4. The printed Table 1 kij cannot reproduce the paper’s own Fig. 1. Used as printed in the van Laar combination of Eq. (10), they give x(CO₂) ≈ 10⁻¹⁷ (a negative-a artifact) and hydrocarbon solubilities ~10× too low, while the paper reports 1–4% AADy on those same data. This work keeps the vapor-phase values untouched and adds an aqueous-phase-only correction dK₀ + dK₁(T−273.15) to k(g,w), regressed in stage 2 — see the Parameters tab.

Numerical verification

The JavaScript engine in this page is a line-by-line port of the Python research prototype. Verified against it to machine precision: Gauss–Legendre nodes, ln φᵢ (both phases, all 6 components), TP flash (phase compositions to 10⁻¹⁴), Langmuir constants (10⁻¹⁵), hydrate fugacity & occupancies (10⁻¹⁵), and equilibrium pressures incl. mixtures and the ice branch (≤10⁻⁷ relative). Cubic roots are computed analytically with the same filtering as the prototype (real roots with Z > B).
